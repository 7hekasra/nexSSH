# 🔐 nexSSH

ابزار سبک و متن‌باز برای **ممیزی امنیتی SSH در Linux** که با Python نوشته شده و به صورت تک‌فایلی اجرا می‌شود.

nexSSH تنظیمات SSH، احراز هویت، دسترسی‌ها، Permission فایل‌ها، وضعیت سرویس، پورت و الگوریتم‌های رمزنگاری را بررسی می‌کند و مشکلات را همراه با شدت و پیشنهاد اصلاح نمایش می‌دهد.

> **این ابزار فقط بررسی می‌کند و هیچ تغییری در سیستم ایجاد نمی‌کند.**

---

## ✨ قابلیت‌ها

- 🔍 بررسی امنیت تنظیمات SSH
- 🔐 بررسی Authentication و ورود `root`
- 🛡️ بررسی دسترسی‌ها و Forwarding
- 🔑 بررسی Permission فایل‌های SSH
- ⚙️ بررسی وضعیت سرویس SSH
- 🌐 بررسی پورت SSH
- 🔒 بررسی Ciphers، MACs و KexAlgorithms
- 📊 محاسبه امتیاز امنیتی از `0` تا `100`
- 📄 تولید گزارش HTML
- 🧩 خروجی JSON
- 📦 بدون وابستگی خارجی
- 📄 تک‌فایلی و کاملاً Read-Only

---

## 🧠 نحوه کار

ابتدا nexSSH تلاش می‌کند تنظیمات مؤثر SSH را با دستور زیر دریافت کند:

```bash
sshd -T
```

در صورت عدم دسترسی، فایل‌های تنظیمات زیر بررسی می‌شوند:

```text
/etc/ssh/sshd_config
/etc/ssh/sshd_config.d/*.conf
```

سپس بررسی‌های امنیتی اجرا شده و برای هر مشکل یک Finding شامل شدت، مقدار فعلی، توضیح و پیشنهاد اصلاح ایجاد می‌شود.

## 🚀 اجرا

برای اجرای کامل:

```bash
sudo python3 nexssh.py
```

فقط بررسی احراز هویت:

```bash
sudo python3 nexssh.py --auth
```

خروجی JSON:

```bash
sudo python3 nexssh.py --json
```

گزارش در مسیر دلخواه:

```bash
sudo python3 nexssh.py --report /tmp/report.html
```

بدون تولید گزارش HTML:

```bash
sudo python3 nexssh.py --no-report
```

---

## 📄 خروجی

در اجرای عادی، فایل زیر ساخته می‌شود:

```text
nexssh_report.html
```

گزارش شامل امتیاز امنیتی، Findingها، شدت مشکلات، مقدار تنظیمات و پیشنهاد اصلاح است.

خروجی JSON نیز برای استفاده در اسکریپت‌ها، داشبوردها و ابزارهای امنیتی قابل استفاده است.

## 🔒 امنیت

nexSSH:

- تنظیمات را تغییر نمی‌دهد
- سرویس را Restart نمی‌کند
- Firewall را تغییر نمی‌دهد
- چیزی نصب نمی‌کند
- کلید خصوصی را نمی‌خواند
- اطلاعات حساس را چاپ نمی‌کند

برای کامل‌تر شدن برخی بررسی‌ها، اجرای ابزار با `sudo` توصیه می‌شود.
